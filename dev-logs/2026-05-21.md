## 遇到的问题

1. **shadcn/ui v4 @base-ui/react API 差异**：Radix UI 使用 `asChild` prop，而 @base-ui/react 使用 `render` prop。全局替换了 header、breadcrumb-nav、alert-dialog trigger、button、dropdown-menu 中的 asChild 用法。
2. **Next.js 16 build 严格类型检查**：开发模式未捕获的 `asChild` 类型错误在生产构建时暴露。
3. **JWT Session 不包含 user.id**：NextAuth v5 默认不在 session 中传递 id，需在 jwt/session callbacks 中手动映射。
4. **date-fns 未安装**：改用原生 `toLocaleDateString` 做日期格式化。
