# 需求文档

## 项目概述

旅游信息管理与分享 Web 应用。用户通过浏览器访问，支持多人跨网络使用。功能涵盖目的地管理、景点/美食/住宿展示、游客评论评分系统、照片上传与展示。

## 目标用户

- 普通用户：浏览旅游信息、发表评论、上传照片
- 管理员：管理目的地及各类实体内容

## 功能需求

### F1 用户系统
- F1.1 邮箱密码注册
- F1.2 邮箱密码登录
- F1.3 登录态保持（30 天）
- F1.4 角色区分：普通用户 / 管理员

### F2 目的地管理
- F2.1 目的地列表（分页、搜索、筛选）
- F2.2 目的地详情（含封面图、描述、地图位置）
- F2.3 管理员可新增、编辑、删除目的地

### F3 景点系统
- F3.1 每个目的地下的景点列表
- F3.2 景点详情（名称、地址、票价、营业时间、联系方式）
- F3.3 景点展示照片上传与管理
- F3.4 管理员可增删改景点

### F4 美食系统
- F4.1 每个目的地下的美食列表
- F4.2 美食详情（名称、地址、菜系、价格区间、联系方式）
- F4.3 美食展示照片上传与管理
- F4.4 管理员可增删改美食

### F5 住宿系统
- F5.1 每个目的地下的住宿列表
- F5.2 住宿详情（名称、地址、类型、星级、设施、联系方式）
- F5.3 住宿展示照片上传与管理
- F5.4 管理员可增删改住宿

### F6 评论系统
- F6.1 1-5 星评分
- F6.2 文字评论（标题 + 内容）
- F6.3 评论可附带照片
- F6.4 用户可编辑/删除自己的评论
- F6.5 管理员可删除任何评论

### F7 照片系统
- F7.1 展示照片上传（拖拽 + 点击）
- F7.2 客户端压缩后上传
- F7.3 缩略图自动生成
- F7.4 图片画廊 + 灯箱查看
- F7.5 评论照片支持

### F8 自动获取（第四阶段）
- F8.1 管理员通过高德 API 搜索 POI
- F8.2 一键导入 POI 基础信息
- F8.3 导入后可手动编辑补充

### F9 交通（预留）
- F9.1 占位页面，后续实现

## 非功能需求

- NFR1：中文界面
- NFR2：浅色/白色 UI 风格，简洁直观
- NFR3：桌面端优先，移动端兼容
- NFR4：支持多用户同时使用
- NFR5：免费服务额度内运行

## 验收标准

1. 用户可注册、登录、浏览目的地
2. 用户可查看景点/美食/住宿详情
3. 用户可发表带评分和照片的评论
4. 管理员可管理所有内容
5. 界面风格统一、操作流畅
