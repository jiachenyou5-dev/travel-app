# 设计规范 — Clay 旅行主题

2026-11-15 按用户指定 E:/设计/Clay 重新制定。该文档替代旧版白色/蓝色设计要求。本次以 DESIGN.md 的明确 token 为准，两张预览用于观察组件与排版；二者冲突时不混用色板。

## 视觉基准

- 浅色主方案：奶油色画布 #fffaf0，近黑文字与按钮 #0a0a0a。
- 二级背景 #faf5e8；浅卡片 #f5f0e0；边框 #ded9cd。
- 六种色块：粉 #ff4d8b、深青 #1a3a3a、紫 #b8a4ed、桃 #ffb084、赭黄 #e8b94a，以及奶油色。薄荷 #a4d4c5 用作插画配色。
- 大标题 weight500，紧凑字距，桌面约56–72px，移动约36–38px；页面标题30–40px。避免把所有标题加粗到700。
- Plain Black 为专有字体，不复制使用；拉丁使用 Inter，中文使用 Microsoft YaHei UI / Microsoft YaHei 系统回退。
- 主容器1280px，桌面横向内边距32px，手机20px；大区块间距96px，移动64px。
- 导航64px；按钮及输入最低44px高、12px圆角；内容卡16px圆角，彩色色块24px圆角。
- 以平面色块、留白、真实黏土材质资产体现层次，不使用大面积渐变、玻璃拟态或重投影。
- 页脚保持暖浅色。

## 结构与页面

- 首页：7/5分栏大标题与黏土主视觉、搜索条、真实数据库统计、三个目的地、行程与游记入口、存在数据时显示真实评论、暖色页脚。
- 目的地：标题与筛选区，三列彩色卡片，现有照片优先；无照片使用明确标为插画的装饰素材。特定城市插画只用于对应城市，其余使用通用旅行主题。
- 详情：目的地简介置于奶油色图文区，照片/景点/美食/住宿标签后展示地图；实体详情保留现有业务字段，统一卡片、间距、标题及输入组件。
- 游记、行程、搜索、登录注册、个人中心及后台共用同一组件和配色；个人中心导航标出当前位置。
- 手机分栏改为单列，标签可横向滚动，操作区保留足够点击区域，关闭非必要的多组浮动快捷按钮，仅保留顾问与按需显示的回顶部。

## 图片与图标

所有应用小图标使用内置 ImageGen 生成的 PNG 位图。不得再导入 Lucide 或手写 SVG 小图标；图标组件位于 src/components/ui/clay-icons.tsx，使用一张6×6透明图集，通过 CSS background-position 显示。

主视觉、目的地三联图及功能插画同样由 ImageGen 生成，落地于 travel-app/public/images/clay/。图集完整保留，不通过手工绘制替代。背景透明，维持原始比例。

后台统计的 SVG 环形图是实际数据图表，不属于 UI 小图标。开发服务器自身工具条不属于应用图标，已关闭可见开发指示器。

素材来源与提示词见 travel-app/public/images/clay/PROMPTS.md。参考字体和 Clay 品牌不作为本应用品牌使用。

## 可用性

- 按钮保留可读文字或 aria-label，位图图标为装饰时 aria-hidden。
- 输入与标签关联，评论编辑和新增表单使用独立 ID。
- 评分可通过原生按钮键盘操作，明确标注星数。
- 当前导航 aria-current，提供跳至主要内容链接。
- 尊重 prefers-reduced-motion。
- 视觉改造不能绕过此前已实现的身份、审核和数据校验。
